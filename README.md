# Circuit Power Tree Designer ⚡

這是一個專為硬體與系統工程師打造的網頁端「電源樹佈局與輔助選型工具」。
本工具旨在協助工程師在設計初期快速進行 **Power IC 選型規劃、視覺化架構整理與資訊匯總**。透過視覺化的多層級架構，快速拉建供電網路，並自動計算基本的電壓、電流與功耗分配，作為 BOM 表規劃與規格審查的基礎參考。

---

## 🛠️ 專案開發狀態與規劃 (Project Status & Roadmap)

這裡詳列了本工具目前已支援的功能與未來預計更新的項目。

### 1. 畫布與佈局系統 (Layout)
- [x] **階層式網格佈局**：基於元件前後級關係的自動對齊。
- [x] **自動避讓機制**：元件位置變動時自動推擠，避免重疊。
- [x] **連線風格切換**：支援垂直總線 (Absolute Grid Bus) 與貝茲曲線。
- [x] **視圖模式**：提供 完整(Full)、精簡(Compact)、僅電源(Power Only) 顯示模式。
- [ ] **自定義工作區尺寸**：調整畫布邊界以適應大型系統。

### 2. 電源運算引擎 (Power Calculation Engine)
- [x] **電壓正向推導**：計算各級輸出電壓與開關壓降。
- [x] **電流反向聚合**：從負載端逐層累加需求電流。
- [x] **功耗分析**：計算單點損耗與系統總消耗預估。
- [x] **動態計算同步**：參數變更時即時重新運算全圖資料。

### 3. 元件模型與定義 (Components)
- [x] **基礎硬體模型**：Source, Converter, Load Switch, Mux Switch, Load。
- [x] **參數警告機制**：輸入電壓或輸出電流超出設定規格時亮軌警示。
- [x] **參數複製貼上**：節點間規格參數的複製與套用。
- [ ] **零件庫 (Component Library)**：儲存常用料號的預設參數。
- [ ] **控制邏輯標記**：支援 EN/PG/I2C 等控制訊號線的靜態佈線。

### 4. 資料管理與輸出 (Data Management)
- [x] **JSON 專案匯入/匯出**。
- [x] **新建專案畫布**：支援一鍵重置至初始狀態。
- [ ] **影像匯出**：支援 PNG/SVG 格式。
- [ ] **設計報表匯出**：生成 PDF/Excel 格式的參數匯總表。
- [x] **編輯歷史**：支援 Undo / Redo 功能。

---

## 🚀 快速開始 (Getting Started)

1. **新增元件**：利用左上角面板點擊新增 Source、Converter 等。
2. **建立連結**：拖曳節點右側的圓點連接至下一級的輸入端。
3. **設定參數**：點擊元件，在右側面板輸入電壓、電流或效率。
4. **分析結果**：直接在畫布元件下方閱讀即時運算的電氣數值。
